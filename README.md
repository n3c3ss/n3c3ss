# n3c3ss — topographic HUD story

Одностраничный Next.js App Router проект на TypeScript. Контент и визуальная структура собраны по исходному ТЗ.

## Запуск

```bash
npm install
npm run dev
```

Production build: `npm run build`, затем `npm start`.

## Реализовано

- Статически рендеримая страница App Router; тексты и ссылки централизованы в `src/lib/content.ts`.
- Таймлайн HERO → OFFER → FAQ → FINAL с пропуском пустых секций, преобразованием scroll ↔ story time и точками отдыха.
- Фиксированная сцена, HUD, клавиатурная навигация, адаптивная раскладка, no-JS текстовый fallback.
- Общий Canvas renderer для OffscreenCanvas Worker и main-thread fallback.
- Процедурное 4D-подобное fBm-поле с бесшовным циклом дыхания, гауссовыми пиками, marching-squares изолиниями и сборкой сегментов в непрерывные контуры.
- Индексные изолинии со свечением и высотными подписями, камера с ключевыми точками, сетка координат, маршрут, узлы и импульсы.
- HUD координат, высоты и количества активированных узлов связан с параметрами камеры и карты.
- Адаптивный DPR и шаг сетки, ограничение частоты кадров для слабых устройств и idle-режим, reduced-motion.
- Посимвольная расшифровка слогана и OFFER-текста, привязанная к локальному времени сцены; исходные строки доступны скринридерам через `aria-label`. HUD-навигация отмечает активную сцену через `aria-current="step"`.
- Интро-проявление изолиний: контуры раскрываются последовательно по высотным уровням, затем проявляются по длине линий. Седловые ячейки marching squares разрешаются по значению в центре ячейки, чтобы избежать случайного соединения ветвей.
- Маршрут рисуется непрерывно по длине кривой, а не скачками между точками; аннотации сцен закреплены за координатами карты и появляются на соответствующих временных отметках.
- Первый экран виден до запуска клиентского контроллера; предусмотрен текстовый fallback при отключённом JavaScript, улучшены мобильная прокрутка FAQ и клавиатурный focus. Координатное преобразование Canvas согласовано с мировыми координатами поля, камеры, маршрута и указателя.
- HUD-навигация и skip-link используют настоящие hash-якоря, привязанные к точкам отдыха таймлайна; ссылки работают как обычные ссылки браузера, а не как JS-кнопки.
- Worker использует back-pressure: контроллер отправляет следующий кадр только после подтверждения завершения предыдущего, поэтому очередь кадров не накапливается на медленных устройствах; при недоступном OffscreenCanvas 2D-контексте выполняется переключение на main-thread fallback.
- Глитч вордмарка запускается при первом появлении и при входе в финальную сцену, с общим ограничением частоты вспышек.
- DOM-эффекты зерна и глитча без сторонних UI/animation библиотек. Буфер поля высот переиспользуется между кадрами, чтобы снизить давление на сборщик мусора. При ошибке Worker переданный Canvas заменяется новым элементом и рендеринг переключается на основной поток. `prefers-reduced-motion` передаётся и в Worker.

## Проверки перед публикацией

Основные модули TypeScript и Worker проходят отдельную строгую проверку. Полный `next build` в текущей среде пока не подтверждён: установка npm-зависимостей ранее завершалась по тайм-ауту. После установки зависимостей проверить Chromium и WebKit на 360×560, 390×844, 768×1024 и 1440×900, reduced-motion, no-JS, консоль и Lighthouse mobile.

Это ещё не финальная приёмка: остаётся браузерный визуальный прогон, измерение производительности на мобильных устройствах и точная настройка темпа интро/аннотаций. В v9 исправлено преобразование координат поля в экранные координаты, добавлена корректная обработка седловых ячеек, повторное использование буфера высот и fallback при сбое Worker. В v10 добавлены реальные hash-якоря для навигации по точкам отдыха, skip-link, ограничение очереди сообщений Worker и fallback при невозможности получить 2D-контекст в Worker. Полный `next build` всё ещё требует установки зависимостей и проверки в браузере.


## v11 — lifecycle и мобильная доводка

- Анимационный цикл приостанавливается, когда вкладка скрыта, и корректно продолжает работу после возврата; при возврате сбрасывается временной delta, чтобы избежать скачка камеры.
- Инициализация Canvas/Worker теперь отменяется при размонтировании компонента и повторяется при возвращении во вкладку, если браузер отложил idle callback.
- Изменение системной настройки `prefers-reduced-motion` во время открытой страницы обрабатывается без перезагрузки.
- Клавиатурные стрелки не перехватываются, когда фокус находится на ссылке, кнопке или поле ввода; добавлена защита от случайной навигации при модификаторах клавиш.
- Ошибки отправки сообщений Worker при изменении размера или кадра переводят рендеринг на основной поток.
- Для небольших экранов уплотнена верхняя HUD-панель, отражение вордмарка скрывается, а фон карты OFFER получил более читаемую координатную сетку. Высота фиксированной сцены использует стабильный `svh` и safe-area отступы.
- Финальный вордмарк оформлен семантическим заголовком второго уровня.

## v12 — reduced motion и доступность

- `prefers-reduced-motion` отключает сглаживание прокрутки и вертикальные сдвиги сцен; остаются только мягкие кроссфейды. История переключается напрямую в положение скролла.
- При включении reduced motion во время открытой страницы сцена сразу синхронизируется с текущей позицией прокрутки. Глитч не запускается ни при наведении, ни при переходах сцен; дыхание рельефа и движения карты замедляются в четыре раза.
- Прогресс истории размечен как доступный progressbar с обновляемым `aria-valuenow`.
- Основной `h1` содержит скрытое для визуального интерфейса описание оффера, FAQ-список получил именованную фокусируемую область для клавиатурной прокрутки на узких экранах.
- Увеличен размер ответов FAQ и микрокопии до 14px.
- Исправлена граница активной сцены: в точке стыка таймлайна HUD теперь сразу указывает на следующую сцену.

## v14 — финальная визуальная доводка

- Вордмарк получил отдельную SVG HUD-рамку с прорисовкой контура, засечками и неоновыми угловыми акцентами; анимация запускается при входе в HERO и FINAL.
- Добавлены Open Graph / Twitter preview 1200×630 и SVG favicon.
- Шрифты переведены на локальные файлы, чтобы сборка не зависела от сетевой загрузки Google Fonts. В текущем архиве используются Lato Black Italic для display и DejaVu Sans Mono для интерфейса; это близкая локальная замена Montserrat / JetBrains Mono, а не те же гарнитуры.
- Добавлен `src/lib/analytics.ts`: сбор событий по умолчанию полностью выключен (`provider: none`); при явном выборе Plausible или Umami используется соответствующий глобальный адаптер. Отслеживаются CTA, вторичная ссылка и просмотры сцен.
- Добавлена визуальная демонстрация `public/preview.html` (после запуска Next.js доступна по `/preview.html`) и самодостаточный `preview-standalone.html`, который можно открыть прямо из файловой системы без Node.js и установки зависимостей.
- Усилена подложка под текст OFFER и уточнены мобильные состояния кнопок и FAQ.
